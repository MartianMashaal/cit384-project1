# CIT 384 Project 1 - Neon Afterimage

Neon Afterimage is a four-page personal-interest site about cyberpunk games, city design, and movement.

GitHub Pages: [https://martianmashaal.github.io/cit384-project1/](https://martianmashaal.github.io/cit384-project1/)

## MDN exploration

| Type | MDN documentation | Use in this site |
| --- | --- | --- |
| Element | [`dfn`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dfn) | Defines cyberpunk and wayfinding on City Design |
| Element | [`ruby`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/ruby) | Pairs a Japanese sign character with its pronunciation |
| Element | [`rt`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/rt) | Supplies the pronunciation within the ruby annotation |
| Attribute | [`loading`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/img#loading) | Lazy-loads the route images |
| Attribute | [`decoding`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/img#decoding) | Requests asynchronous image decoding |
| Attribute | [`referrerpolicy`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a#referrerpolicy) | Omits the referring page's address when opening MDN links |

Comments beside the first use of each selected feature explain its purpose. The Play Route page also has a linked reference table.
